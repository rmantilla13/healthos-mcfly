healthOS

Privacy Policy

Last updated October 16, 2026

healthOS is a personal health dashboard at health.mcfly.bot. It is run by Ricky Mantilla for his own use. It is not offered to the public, and it has no other users.

What data it uses

  • WHOOP, read through WHOOP's official API only after the owner signs in to WHOOP and approves access. healthOS reads recovery, sleep, physiological cycles and strain, workouts, basic profile details (first name) and body measurements. It never writes to WHOOP.
  • Apple Health, from the owner's own Health export or from the healthOS iPhone app, which sends daily summaries.
  • An optional profile photo, processed on the owner's own Mac.

How it is used

The data is used only to show the owner their own charts, trends and summaries. healthOS has no advertising, no analytics or tracking, and no profiling. It does not sell, rent or share data with anyone.

Where it is stored

  • The app is hosted on Vercel. Data is stored in a Postgres database run by Neon in the United States (US East).
  • All traffic is encrypted in transit (HTTPS).
  • Reading any data requires the owner's password.
  • The only cookie is a sign-in session cookie, which is strictly necessary.
  • WHOOP access tokens are stored server-side and are never exposed to the browser.

Service providers

These providers handle data only to run the service: WHOOP (the data source), Vercel (hosting) and Neon (database). Their own privacy policies apply to their services.

Keeping and deleting data

  • Data is kept until the owner deletes it.
  • Disconnecting WHOOP in healthOS revokes the app's access with WHOOP and deletes the stored tokens.
  • WHOOP access can also be revoked at any time from WHOOP's own account settings.
  • The owner can delete imported data from the app, or remove the database entirely.
